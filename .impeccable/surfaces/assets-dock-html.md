# DevMap Metro Dock
Mode: Operate. Target: assets/dock.html and embedded assets/metro-core.js.
Audience: developers supervising local worktrees and their Codex tasks.
Primary action: open the exact task linked to a workspace. Supporting action: locate unfinished work.
Confirmed visual authority: docs/audits/assets/2026-09-04-metro-preflight/approved-concept-3.png, with explicit connection/status corrections in docs/superpowers/specs/2026-09-04-devmap-metro-topology-design.md.
Established direction; do not run another concept tournament. This is an interactive data renderer, not a raster illustration.

## Direction contract
THESIS: A traceable development metro makes ownership and unfinished code legible in a narrow Dock.
OWN-WORLD: Light neutral surfaces, charcoal main, stable Underground-inspired branch colors, precise station rings, quiet task rows and separate warning shapes.
STORY: Trace origin, find workspace, identify Agent, inspect unfinished work, open its task.
FIRST VIEWPORT: Compact title and attention summary; readable current workspace on connected rails with active names; visible pan and locate controls; inspector only on selection.
FORM: User-selected concept 3; existing approval replaces seed selection. Preserve its visual language and repair its missing/ambiguous edges using the verified graph.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

Signature interaction: locate a workspace, trace its true checkout connection and expand its tasks without changing branch identity.
Motion: immediate positioning under reduced motion; otherwise short focus/selection feedback only, no entrance choreography.
