# Reported Agent working directory

The host lists the current chat at the repository root while commands for this task run in the linked `devmap-journey-focus` worktree. Correcting the map source exposed a separate gap: passenger association used only host cwd. The source highlight correctly moved, but the chat remained at its registered directory. Changing a map label or overwriting host cwd would hide this distinction.

Implemented a bounded optional `codex_tasks[].workingDirectory` observation containing an exact worktree path, Unix observation time and `source: agent_report`. The server validates an existing canonical worktree in this repository and rejects unsupported sources or future timestamps beyond 30 seconds of clock tolerance before replacing the inventory. The caller must establish the exact task identity and check its actual execution directory; the report is not authenticated host execution telemetry.

The chat is placed once at its reported working worktree. Its original host cwd is retained as `registered_workspace_path`, navigation retains the verified Codex task ID, and the inspector labels the association as Agent reported. Existing Presence entries for that task at other worktrees do not duplicate it. Other tasks do not move. The host-association journal continues to record host cwd and does not invent host migration from an execution report.

Git-only refresh retains the report and its timestamp. A new task inventory without a report uses host cwd; the Skill requires a new actual directory check when reporting the calling Agent's working location. The combined placement observation is capped by its oldest working-directory evidence, while the original host inventory timestamp remains separate. Expired evidence therefore cannot certify either occupancy or absence. This is intentionally conservative across the map. No new Git automation or creation-history ingestion is included.

Validation: 170 Node tests; 89 focused Rust tests across dock model, MCP, map MCP, viewer, plugin and UI contracts; cargo build, fmt, clippy library with warnings denied, and diff whitespace checks. Regression cases cover a chat registered at root working in another worktree, unrelated chats staying at root, invalid reports leaving prior inventory intact, omitted reports, preserved journal provenance, stale reports surviving refresh without becoming fresh, archived chats, and safe frontend task navigation. Embedded HTML remains below 160 KiB; CSS separator whitespace was reduced without changing declarations.

Real browser verification used the actual repository and a fresh partial host inventory, with only the verified calling task supplying its checked command worktree. The development platform shows one observed passenger, and its inspector shows `完善自动 Git 工作流编排`, `Agent · codex`, and the reported association. This is a development preview; no commit, push, merge or installed-plugin replacement was performed for this correction.
