用户已确认统一产品方向并授权进入阶段 1–2 开发。本次在既有 `codex/devmap-journey-focus` 隔离工作区实施；未提交、推送、合并或更新安装插件。

## 交付内容

- Worktree 主标题使用真实分支名；目录单独显示。Detached HEAD 明确展示短 SHA。共享 HEAD 保留一个提交站点，能选择不同工作区。
- `main` 标签挂到其真实引用目标；同提交的引用合并标注。其他引用可在分支索引和提交详情中定位，不把大量文字铺到轨道交叉处。
- 当前上下文工作区与分支 tip 分开。地图的当前上下文来自 source workspace；宿主登记路径是任务关联证据，不能证明 Agent 每条命令的实际 cwd。
- 站台显示任务观测、未提交修改及包含/发布状态。共享 HEAD 上的状态行对应主标题下显示的工作区，完整组内状态可在选择列表和详情检查。
- 只有可靠确认无人、干净、HEAD 已包含、有稳定引用且无开放计划/警报的非当前工作区标为 Retained workspace；只降低视觉权重，不隐藏未知/风险工作区，不进行清理。
- 起点事实新增版本 `devmap/workspace-facts/1`：创建证据、计划建立点、当前共同祖先分别存在；原始计划建立时间不会被后续编辑时间覆盖。
- 地图和 Agent 共用身份、起点和绑定数据；Agent 响应增加 observation_revision，区分内容版本与观测刷新。
- 宿主任务关联与观测到的迁移持久化到有界 journal。迁移时间未知，显示观察时间；最新观测水位单独保存，迟到的旧消息不能制造反向迁移。
- 无效起点或超限绑定详情在渲染前拒绝，保留之前有效地图。
- 保留原有地铁配色、拓扑、虚线计划与独立详情面板；站台空间跟随文字尺寸，乘客展开不改变轨道位置。

## 明确的范围调整

Ruling: **真实 Worktree 创建事件采集保留为未完成项**。当前 Git/宿主接口没有可靠创建事件、创建 OID 和发生时间；新枚举到目录、共同祖先、计划开始均不能代替它。此版提供诚实的 unknown 契约和已记录证据的展示路径；支持的宿主事件或 P4 执行器交付后才能填入实际创建记录。代价是旧工作区与当前外部创建的工作区仍无法画出已证明的发车事件。

Ruling: 不默认隐藏旧工作区，只给满足条件的保留站台降权。任务名单常不完整，先保证可发现性；全图继续使用现有可读字号与滚动，不增加压缩全历史的第二套布局。

Ruling: 起点导航只保留已记录创建点或共同祖先、HEAD 和目标三个重点。计划建立点、创建未知说明和绑定历史放进工作区详情，避免挤掉窄栏中的交付目的地。

Ruling: 保持 160 KiB 嵌入资源限制。移除已无调用点的旧站点/引用/边界渲染函数及旧全图样式，未引入新的打包依赖或扩大预算。
